# Авто під розбірку

Кожні 20 хвилин перевіряє нові оголошення на AUTO.RIA за моделями з `config.json`
і надсилає в Telegram ті, що схожі на авто під розбірку (запчастини, після ДТП, не на ходу).

Секрети (Settings → Secrets and variables → Actions → New repository secret):
- `RIA_API_KEY` — ключ з developers.ria.com
- `TELEGRAM_BOT_TOKEN` — токен від @BotFather

## Таксі-бот (клас Комфорт, Львів)

Окремий бот у папці `taxi/`: кожні 20 хвилин перевіряє AUTO.RIA за списком моделей для таксі
(`taxi/config.json`: роки, ціна до $9–10k, пальне, об'єм двигуна, без дизеля) і надсилає в Telegram
нові оголошення та ті, де знизили ціну. Повідомлення позначені 🚕, оголошення зі Львова — ⭐, після ДТП — ⚠️.

- Дані беруться зі сторінки пошуку auto.ria.com (ключ не витрачається); якщо сайт недоступний — через `RIA_API_KEY`.
- Використовує той самий `TELEGRAM_BOT_TOKEN`. Щоб таксі-оголошення йшли в окремий чат/групу,
  додайте секрет `TAXI_CHAT_ID` (інакше — у той самий чат, що й розбірка).
- Стан (бачені оголошення) — `taxi/state.json`, зберігається комітом після кожного запуску.
- Ручний запуск: Actions → «Таксі (Комфорт, Львів)» → Run workflow.
